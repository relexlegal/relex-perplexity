# Security

Relex lets you use Perplexity on legal matters without exposing client PII to the model.

- MCP: `https://relex.legal/api/mcp`
- Auth: OAuth 2.1 + PKCE (browser), or API key fallback
- Party data sealed client-side; documents read and redacted by the Relex Private Model on Relex servers by default
- Report issues: security@relex.legal
